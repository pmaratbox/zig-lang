# 0004 — Conditionals

Compare `n` against 10 and print whether it's less, equal, or greater. Like
Rust, Zig's `if`/`else` is an expression (`const x = if (cond) a else b;`).
The condition goes in parentheses; braces are required for bodies. Edit `n`
to `10` or `15` to exercise the other branches.

## Run

    zig run main.zig
