# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. Format specifiers pick the base: `{x}` for hex, `{o}` for octal, and `{b}` for binary, all without a prefix. They apply to any integer value passed to the formatter.

## Run

    zig run main.zig
