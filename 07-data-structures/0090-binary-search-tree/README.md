# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. `?*Node` optional pointers form the tree; `allocator.create` heap-allocates each node, and the in-order traversal prints the sorted values.

## Run

    zig run main.zig
