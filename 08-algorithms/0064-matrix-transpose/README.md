# 0064 — Matrix Transpose

Transpose the 2x3 matrix `[[1, 2, 3], [4, 5, 6]]` (swap rows and columns) and print the resulting 3x2 matrix, one row per line: `1 4`, `2 5`, `3 6`. A fixed `[2][3]i32` is printed column-major (`matrix[i][j]` with `j` outermost) to emit the transpose; `.len` gives each dimension.

## Run

    zig run main.zig
