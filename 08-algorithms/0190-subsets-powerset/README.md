# 0190 — Subsets (Power Set)

Generate the power set of [1,2,3] in bitmask order 0..7 (empty printed as `{}`), one subset per line space-separated. For mask 0..7, include element i when bit i is set; empty set prints {}, with `{{}}` escaping the braces in the format string.

## Run

    zig run main.zig
