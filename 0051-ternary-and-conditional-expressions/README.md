# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Zig has no `?:`; `if` is an expression — `if (cond) a else b` — that yields a value. (`?` and `orelse` are reserved for optionals, not conditionals.)

## Run

    zig run main.zig
